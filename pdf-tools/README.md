# PDF Tools

A Flask web app for merging, splitting, converting, compressing, editing,
signing, redacting, OCR-processing, comparing and summarizing PDF files.

## Deploy on Render

1. Create a GitHub repository and upload the contents of this folder.
2. In Render, choose **New > Blueprint** and connect the repository.
3. Render will read `render.yaml`, build the Docker image and create the web
   service. The first build can take several minutes because it installs OCR,
   PDF and LibreOffice packages.
4. Open the generated `onrender.com` URL after the service reports **Live**.

The included Docker image provides Tesseract (English and Simplified Chinese),
Poppler and LibreOffice. `SECRET_KEY` is generated by Render and is not stored
in the GitHub repository.

### Free-plan notes

- The service can sleep while idle, so the first request may be slow.
- Uploaded and generated files are temporary. They can disappear when the
  service restarts or redeploys.
- Keep one Gunicorn worker because background job state is currently stored in
  the process memory.

## Run locally with Docker

```bash
docker build -t pdf-tools .
docker run --rm -p 5001:10000 -e SECRET_KEY=local-development-key pdf-tools
```

Then open <http://localhost:5001>.

## Run locally with Python

Install Tesseract, Poppler and LibreOffice first, then run:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

The app listens on <http://localhost:5001> by default.
